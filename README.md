# MathEnglish 🧮

Ứng dụng web học Toán bằng Tiếng Anh (Math English) trực quan, tương tác cao dành cho mọi lứa tuổi từ cơ bản đến nâng cao.

## ✨ Tính năng nổi bật

1. **📚 Kho từ vựng đa dạng theo chuyên đề**:
   - Phép tính cơ bản (Plus, Minus, Times, Divided by, Equals)
   - Hình học & Không gian (Triangle, Square, Rectangle, Circle, Perimeter, Area, Angle)
   - Phân số & Tỉ lệ (One half, One quarter, Fraction, Percentage)
   - Đo lường & Thời gian (Length, Weight, Volume, Minute & Second)
   - Từ khóa giải toán (In total, Left, More than, Less than, Share equally)
   - Tích hợp phát âm chuẩn bản xứ (Web Speech API), phiên âm IPA và đọc bồi tiếng Việt.

2. **🎴 Thẻ Flashcard 3D lật thẻ**:
   - Giao diện thẻ 3D xoay lật mượt mà.
   - Chế độ ghi nhớ tiến độ học tập (Đã thuộc / Chưa thuộc).
   - Xáo trộn thẻ ngẫu nhiên (Shuffle).

3. **🔊 Bàn tính đọc câu tiếng Anh**:
   - Nhập số và phép tính, hệ thống tự động dịch và đọc to nguyên câu bằng tiếng Anh.

4. **📖 Bài toán đố mẫu có lời giải**:
   - Dịch nghĩa câu toán thực tế kèm phân tích từ khóa chỉ điểm.

5. **🎮 Thử thách Quiz & Confetti**:
   - Bộ câu hỏi trắc nghiệm sinh động.
   - Hiệu ứng pháo hoa Confetti và âm thanh chúc mừng khi hoàn thành.

## 🚀 Hướng dẫn chạy cục bộ

### Chạy trực tiếp
Mở file `index.html` bằng trình duyệt web bất kỳ (Chrome, Edge, Firefox, Brave...).

### Hoặc chạy qua Node.js server
```bash
node server.js
```
Truy cập: [http://localhost:3000](http://localhost:3000)
